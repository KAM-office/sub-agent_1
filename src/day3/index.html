PART 2 ヒヤリハット事例の分析
⚡ ヒヤリハットとは
ハインリッヒの法則：1件の重大事故の背後に29件の軽微事故、300件のヒヤリハット
💡 ヒヤリハットの価値
「事故にならなかったから良かった」ではなく、「次は事故になるかもしれない」と捉える。ヒヤリハットの報告と共有が事故ゼロの鍵

PART 2 ヒヤリハット事例の分析
📋 ヒヤリハット事例集（1/2）
🚛
事例1：左折巻き込み
交差点で左折時、ミラー死角に自転車がいた。内輪差で接触寸前。
対策：左折前に必ず一時停止。左ミラー＋目視で確認
🅿️
事例2：ホーム接車時の落下
バック時に渡し板の位置がずれ、パレットが傾いた。荷崩れ寸前。
対策：渡し板の接地位置を毎回確認。15cm以上内側に設置
🌧️
事例3：雨天時のスリップ
雨天の下り坂でブレーキが効きにくく、前方車両に急接近。
対策：雨天時は車間距離2倍。下り坂ではエンジンブレーキ併用

PART 3 エコドライブ・燃費管理
🌿 エコドライブ 6つのテクニック
🚀
ふんわりアクセル
急加速を避け、5秒で20km/hを目安にゆっくり発進
🛑
急ブレーキ回避
車間距離を十分に取り、早めのアクセルオフで減速
🔄
アイドリングストップ
待機中・荷待ち中はエンジンを切る。5秒以上の停止で効果あり
🛞
タイヤ空気圧管理
空気圧不足は燃費悪化の原因。月1回の点検を習慣化
📊
デジタコ活用
速度パターンを確認し、燃費効率の良い運転を意識
🗺️
ルート最適化
指定順路を守りつつ、渋滞情報を事前に確認
💰 コスト効果
エコドライブで燃費が約10%改善。会社全体で年間数百万円のコスト削減に貢献

PART 3 エコドライブ・燃費管理
📊 燃費管理の実践
燃費の目安 2t車：8〜10km/L ｜ 4t車：5〜7km/L ｜ 8t車：3〜5km/L
  • 毎日の燃料消費量を記録する
  • 前月との比較で改善度を確認
  • デジタコの燃費データを活用
  • 急操作回数の推移を意識する
🚫 燃費を悪化させる運転
  • 急発進・急加速（燃費30%以上悪化）
  • 不要なアイドリング（10分で約130ccの無駄）
  • 速度超過（適正速度を超えると燃費急落）
  • タイヤ空気圧不足（10%不足で3%燃費悪化）

PART 4 顧客対応・クレーム処理
📋 想定されるクレーム事例と対応
📦 事例1：配達遅延のクレーム

「予定時刻に届かない」と局員から指摘

対応：①お詫び → ②原因説明（渋滞等）→ ③到着見込みを報告 → ④運行管理者にも連絡
🚛 事例2：荷物の破損申告

「パレットが傾いて中身が散乱している」

対応：①お詫び → ②現場写真撮影 → ③局員と状況確認 → ④会社へ即時報告 → ⑤事故報告書作成
🅿️ 事例3：駐車マナーの苦情

「ホーム前に長時間駐車して邪魔」

対応：①お詫び → ②速やかに車両移動 → ③上司に報告 → ④再発防止を約束
💬 事例4：態度への不満

「挨拶がない」「態度が悪い」

対応：①真摯にお詫び → ②自分の行動を振り返る → ③上司に報告 → ④改善を宣言

PART 4 顧客対応・クレーム処理
🛡️ クレーム対応の鉄則
  1. まず相手の話を最後まで聞く（遮らない）
  2. 誠意を持ってお詫びする（言い訳をしない）
  3. 事実を正確に確認・記録する
  4. 自己判断せず、必ず上司・運行管理者に報告する
  5. 再発防止策を考え、実行する
🚨 絶対禁止
相手と口論する・言い訳する・その場で約束する（権限外のことを勝手に決めない）

PART 5 健康管理（疲労・睡眠）
😴 睡眠と安全運転の関係
睡眠不足は飲酒運転と同等の危険 4時間睡眠が3日続くと、血中アルコール濃度0.06%相当の判断力低下
✅ 推奨される睡眠
  • 毎日7〜8時間の睡眠を確保
  • 就寝・起床時間を一定にする
  • 寝る前のスマートフォンを控える
  • カフェインは就寝6時間前まで
🚫 危険な兆候
  • あくびが頻繁に出る
  • まぶたが重い・目がかすむ
  • 車線をはみ出しそうになる
  • 信号の変化に気づくのが遅い
