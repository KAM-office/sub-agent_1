# Professional Driver Blueprint - 製品仕様書

## 1. プロダクト概要

### プロダクト名
**Professional Driver Blueprint**（プロドライバー育成プログラム）

### コンセプト
運送・物流業界の新人ドライバーが、入社直後の3日間（1日目・2日目 + 2週間後のフォローアップ3日目）で、安全運行・法令遵守・顧客対応の基礎を体系的に習得するための座学研修資料。PDF印刷を前提としたA4横スライド風HTMLで、視覚的に分かりやすく、研修講師がそのまま使用できるクオリティを目指す。

### ターゲットユーザー
- **主対象**: 運送・物流会社に入社した新人ドライバー（業界未経験者を含む）
- **副対象**: 研修を実施する教育担当者・運行管理者（講師用資料として使用）

## 2. 機能一覧

### 機能F-01: 共通CSSフレームワーク
- **説明**: 全3日間の研修資料で統一的に使用するスタイルシートを提供する。A4横（ランドスケープ）レイアウト、プロフェッショナルな青系カラースキーム、ページ番号・セクションヘッダー表示、印刷用CSS（`@media print`）を含む。画面表示とPDF印刷の両方で適切に表示される。
- **優先度**: Must
- **受け入れ基準**:
  - A4横（297mm x 210mm）のスライド風レイアウトが正しく表示される
  - 青系カラースキームで統一されたプロフェッショナルなデザインである
  - 各スライドにページ番号が表示される
  - 各スライドにセクションヘッダー（当該セクション名）が表示される
  - `@media print` で改ページが適切に制御される（1スライド = 1ページ）
  - ブラウザからのPDF印刷時にレイアウトが崩れない（Chrome / Edge で確認可能な品質）
  - 図表・アイコン・色分けなどの視覚要素に対するスタイルが定義されている
  - タイトルスライド、コンテンツスライド、セクション区切りスライドなど複数のスライドタイプに対応するクラスが用意されている

### 機能F-02: 1日目研修資料「会社と業界の基礎」
- **説明**: 入社初日に実施する基礎研修の資料。会社概要・経営理念・組織体制、運送業界の基礎知識（法規制、業界動向、2024年問題）、ドライバーの役割と心構え、安全運転の基本（交通法規、車両点検）、ビジネスマナー・報連相の5セクションで構成。20〜30スライド。
- **優先度**: Must
- **受け入れ基準**:
  - 以下の5セクションが全て含まれている:
    1. 会社概要・経営理念・組織体制
    2. 運送業界の基礎知識（法規制、業界動向、2024年問題）
    3. ドライバーの役割と心構え
    4. 安全運転の基本（交通法規、車両点検）
    5. ビジネスマナー・報連相
  - 合計20〜30スライドの範囲に収まっている
  - タイトルスライド（研修日タイトル・日付・対象者）が含まれている
  - 各セクションにセクション区切りスライドがある
  - 目次スライドが含まれている
  - 2024年問題（時間外労働上限年960時間、輸送能力不足の試算等）について正確な情報が記載されている
  - 改善基準告示の基本的な数値（拘束時間原則284時間/月、1日原則13時間以内等）への言及がある
  - 視覚的な要素（図表、アイコン、色分け、リスト等）が効果的に使用されている
  - 共通CSSを使用し、一貫したデザインである
  - ブラウザで開いてPDF印刷した際に全スライドが正しく出力される

### 機能F-03: 2日目研修資料「実務知識と安全管理」
- **説明**: 入社2日目に実施する実務研修の資料。車両の構造と日常点検方法、運行管理の基礎（運行前点呼、アルコールチェック）、積荷の取扱い・荷崩れ防止、労働時間管理（改善基準告示）、事故・災害時の対応手順、デジタコ・ドラレコの使い方の6セクションで構成。20〜30スライド。
- **優先度**: Must
- **受け入れ基準**:
  - 以下の6セクションが全て含まれている:
    1. 車両の構造と日常点検方法
    2. 運行管理の基礎（運行前点呼、アルコールチェック）
    3. 積荷の取扱い・荷崩れ防止
    4. 労働時間管理（改善基準告示）
    5. 事故・災害時の対応手順
    6. デジタコ・ドラレコの使い方
  - 合計20〜30スライドの範囲に収まっている
  - タイトルスライド・目次スライドが含まれている
  - 各セクションにセクション区切りスライドがある
  - 運行前点呼の手順（対面実施、アルコール検知器使用、健康状態確認等）が具体的に記載されている
  - アルコール検知器の使用義務について正確な情報が記載されている
  - 改善基準告示の詳細数値が正確に記載されている:
    - 1ヶ月の拘束時間: 原則284時間以内
    - 1日の拘束時間: 原則13時間以内、最大15時間（14時間超は週2回まで）
    - 1日の休息期間: 継続11時間以上が基本、最低9時間
    - 連続運転時間: 4時間以内
    - 年間拘束時間: 原則3,300時間以内
  - 日常点検の具体的なチェック項目が示されている
  - 事故発生時の対応フロー（初動対応の手順）が分かりやすく示されている
  - 視覚的な要素が効果的に使用されている
  - 共通CSSを使用し、1日目と一貫したデザインである

### 機能F-04: 3日目研修資料「実運行振り返りと応用」
- **説明**: 2週間の同乗研修後に実施するフォローアップ研修の資料。同乗研修の振り返り・経験共有、ヒヤリハット事例の分析、エコドライブ・燃費管理、顧客対応・クレーム処理、健康管理（疲労、睡眠）、今後のキャリアパスと目標設定の6セクションで構成。20〜30スライド。
- **優先度**: Must
- **受け入れ基準**:
  - 以下の6セクションが全て含まれている:
    1. 同乗研修の振り返り・経験共有
    2. ヒヤリハット事例の分析
    3. エコドライブ・燃費管理
    4. 顧客対応・クレーム処理
    5. 健康管理（疲労、睡眠）
    6. 今後のキャリアパスと目標設定
  - 合計20〜30スライドの範囲に収まっている
  - タイトルスライド・目次スライドが含まれている
  - 各セクションにセクション区切りスライドがある
  - 同乗研修の振り返りセクションでは、受講者が記入・発表できるワークシート的なスライド（記入欄や問いかけ）が含まれている
  - ヒヤリハット事例は具体的なシナリオ（3〜5件程度）が提示されている
  - エコドライブの具体的なテクニック（急加速・急減速の回避、アイドリングストップ等）が記載されている
  - 顧客対応では、想定されるクレーム事例と対応例が含まれている
  - 健康管理では睡眠時間の目安や疲労のセルフチェック方法が含まれている
  - キャリアパスでは目標設定シート的なスライド（記入欄）が含まれている
  - 3日間の研修全体を総括するまとめスライドがある
  - 視覚的な要素が効果的に使用されている
  - 共通CSSを使用し、1日目・2日目と一貫したデザインである

## 4. 非機能要件

### パフォーマンス要件
- 各HTMLファイルはブラウザで即座に表示される（外部CDNへの依存を最小限にし、オフライン環境でも表示可能であることが望ましい）
- PDF印刷処理がブラウザの標準印刷機能で問題なく完了する

### セキュリティ要件
- 外部スクリプトの読み込みは最小限とする（研修資料のため、基本的にはHTML + CSSのみで構成）
- 社内研修用途のため、外部サービスへのデータ送信は行わない

### ユーザビリティ要件
- 研修講師がHTMLファイルをブラウザで開くだけで使用開始できる（ビルド手順不要）
- PDF印刷手順が直感的である（ブラウザの印刷 → A4横 → PDF保存の手順で完結）
- スライドの文字サイズは、研修室のプロジェクターやモニターに投影した際にも読みやすいサイズを確保する
- 色覚多様性に配慮し、色だけに依存しない情報伝達を行う（アイコンや形状の併用）
- 新人ドライバー（業界未経験者含む）が理解できる平易な日本語を使用し、専門用語には初出時に簡潔な説明を付ける

## 5. 要確認事項

以下の項目は、プロンプトから明確に判断できなかったため、必要に応じて確認・調整が望ましい。

1. **会社固有情報の扱い**: 「会社概要・経営理念・組織体制」セクションは、テンプレート形式（プレースホルダーで作成し、各社がカスタマイズ可能）とする前提で進める。
2. **画像・イラスト素材**: スライドに使用する図表やアイコンは、外部画像ファイルに依存せず、CSS・SVG・Unicode等で視覚要素を表現する方針とする。
3. **受講者配布用と講師用の区別**: 受講者・講師共用の1種類のみ作成する前提とする。
4. **言語**: 全て日本語で作成する。

## 6. 補足: 法規制情報の参照元

本仕様書で言及した法規制情報は以下の公的情報に基づく。Generator が研修資料内のコンテンツを作成する際にも、これらの情報を正確に反映すること。

### 改善基準告示（2024年4月改正施行）
- 1ヶ月の拘束時間: 原則284時間以内（労使協定により年6ヶ月まで310時間まで延長可、ただし年間3,400時間以内）
- 1年の拘束時間: 原則3,300時間以内
- 1日の拘束時間: 原則13時間以内、最大15時間（14時間超はできるだけ少なく）
- 1日の休息期間: 継続11時間以上が基本、最低9時間
- 連続運転時間: 4時間以内

### 2024年問題
- 2024年4月から時間外労働上限規制適用（年960時間）
- 対策なしの場合、2024年に輸送能力14.2%不足、2030年に34.1%不足の試算
- 中継輸送、共同配送、DX推進等が業界対策として進行中

### アルコール検知器義務化
- 貨物自動車運送事業者: 営業所ごとにアルコール検知器を備え付け、乗務開始前・終了後の点呼時に使用義務
- 2023年12月以降、白ナンバー事業者にもアルコール検知器使用が義務化
